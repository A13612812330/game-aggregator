## 二、byrutgame.org（俄语 PC 游戏站）

### 2.1 四个判据

| 判据 | 实测值 | 怎么测的 |
|---|---|---|
| **访问 / 反爬** | HTTP 200 · **无 CF 挑战** | 直取首页 274 KB |
| **规模** | 站内自报 **Всего игр: 56 111**（56,111 款） | 首页 `br_stat1` 计数块 |
| **可枚举** | 年份归档 `games-{1990…2027}-years/` **38 个**；2026 归档 **253 页分页** | 归档页链接解析 |
| **按名反查** | `GET /index.php?do=search&subaction=search&story=<词>`：<br>「Dave the Diver」**命中 25 条**（含 `30270-dave-the-diver.html`）<br>「潜水员戴夫」命中 24 条 | 逐个实测 |

### 2.2 下载出口 —— **取到了真种子，不是"应该有"**

```
GET https://byrutgame.org/index.php?do=download&id=211070
  Referer: https://byrutgame.org/53814-minecraft-dungeons-2.html
→ HTTP 200 · Content-Type: application/x-bittorrent · 193,778 B
→ 首字节：d8:announce22:http://bt.t-ru.org/ann13:a   ← bencode 结构，真种子
```

页面上的出口有**两类**（同一款同时给）：

| 出口 | 形态 |
|---|---|
| `…/?do=download&id=211070` `download="Minecraft Dungeons 2_v_1.1.1.0_2026.torrent"` | **种子下载** |
| 「Скачать БЕЗ торрента」（不用种子下载）→ `прямая ссылка · uTorria` | **直链**（托管在 utorria.ru） |

### 2.3 门槛的准确形态（**这是最容易误判的一处**）

- ✗ **裸取** `?do=download&id=…` ⇒ **403 `Access denied`**（13 字节）
- ✓ **带 `Referer: <该款详情页>`** ⇒ **200 + 完整种子**

⇒ 是**防盗链**，不是付费墙、不是登录墙。
（页面里确实出现过 `oplata.info`（俄罗斯支付平台），但那是一条 `style="display:none"` 的**推广卡**，与下载无关；也没有「донат / VIP / подписка」类阻断字样。）

### 2.4 已识别的接入难点

1. **语言**：站点是俄语。但 **H1 是英文游戏名**（`Dave the Diver` / `Gears of War: E-Day` / `CONTROL Resonant`）⇒ 可走现有 `data/mod-match.js` 的**英文段匹配**（库里 title 是 `中文名/英文名` 拼接串，英文段本就在索引里）。
2. **抓取量**：56,111 款全量不现实；**按需反查可行**（搜索接口免登录、GET）。
3. **产物形态是种子**：与现有全网盘渲染不同，前端要新增「⬇ 种子」通道类型。

## 三、ran-ran.top（ranran浮力社 · 中文综合资源站）

### 3.1 四个判据

| 判据 | 实测值 |
|---|---|
| **访问 / 反爬** | HTTP 200 · **无 CF 挑战** · WordPress（BEGIN 主题） |
| **定位** | ⚠️ **不是游戏站** —— 12 个分类：资源分享（电脑软件/安卓应用/苹果应用/**游戏相关**/电视盒子/实用工具/Windows）、技术分享、趣站分享、漫画推荐、动漫影视 |
| **游戏页** | `/{id}.html`（如 `46297.html`） |
| **按名反查** | `GET /?s=<词>`：搜「潜水员戴夫」命中 3 个 id（`963` / `524` / `7`） |

### 3.2 下载出口 —— **一页 5 个网盘，全部免登录**

详情页的「下载地址」按钮指向 `…/begin/download.php?id=NDYyOTc=`（`NDYyOTc=` 是帖 id `46297` 的 base64），
取回来是一张 **42 KB 的下载页**，里面直接列出：

| 盘口 | 链接 | 备注 |
|---|---|---|
| 百度网盘 | `pan.baidu.com/s/1fL93banitVwwvVc4raDkpQ?pwd=gq9x` | **带提取码** |
| 夸克网盘 | `pan.quark.cn/s/a6b32f4bb0ca` | |
| 123 云盘 | `www.123684.com/s/6xrZVv-CeaJ` | 现有源**没有**的盘口 |
| 迅雷网盘 | `pan.xunlei.com/s/VOpd3dU42dpdVBoUTLpLpLRFA1?pwd=85gn` | 带提取码 |
| UC 网盘 | `drive.uc.cn/s/576adb3296ce4` | 现有源**没有**的盘口 |

### 3.3 门槛的准确形态

- ✗ 裸取 `download.php` ⇒ **200 但空体（0 字节）**
- ✓ 带 `Referer: <详情页>` + `X-Requested-With: XMLHttpRequest` ⇒ **200 + 42 KB 下载页**

页面上「登录/注册」出现 **16 次，全部是导航栏按钮与注册条款**（`page_id=152`），
**没有任何一处拦下载** —— 「请登录 / 会员 / 回复可见」类文案实测为 **0**。

### 3.4 已识别的接入难点

1. **需要两步取数**：详情页拿 `download.php` 地址 → 再取一次才见网盘链（比机地帖「正文里就有链」多一跳）。
2. **匹配成本低**：站点是中文，游戏名与端游库中文段**直接可匹配**（比 byrutgame 更省事）。
3. **非游戏内容占比高**：全品类站，按 `游戏相关` 分类抓会漏掉放在别的分类下的游戏贴。
