# v10.108 · 管理台改白（白底 + 三个参考各借一层）

> 2026-10-23 · 只改视觉。不动业务、不动接口、不动任何渲染逻辑（除了资料完整度那一格的表达）。

## 0. 用户原话

> 「我需要你将界面优化：页面我需要白色的
> 页面：https://recapo.ai/zh/tools/link-to-video/
> UI：https://www.boardui.com/zh-hans/components」

追问「改哪个界面 / 白到什么程度」，用户回：

> 「后台管理 admin.html」 / 「白底，其他可以参考 https://designeer.xyz/?sort=views」

## 1. 三个参考，各借的是**不同的一层**（别混为一谈）

这是本轮最容易做错的地方：三个参考站里**有两个本身是深色**，照抄底色会得到完全相反的结果。

| 参考 | 实测到的事实 | 本轮借的是 | **没借**的 |
|---|---|---|---|
| recapo.ai `/zh/tools/link-to-video` | 应用壳是深色：`--ui-bg:#050505` / `--ui-card:#121212` / `--ui-r-card:16px` / `--ui-text:#f4f4f4`（2026-10-23 从它 5 个 CSS 里直抽） | **排版与分节**：小标签 → 大标题 → 一句导语；分节用发丝线，不用一层层卡片框；留白大 | 底色、深色卡片 |
| boardui.com `/zh-hans/components` | React + Tailwind、78 个组件、共享 design token、`rounded-2xl`、`border-border-*-default` | **组件形态**：1px 细边框 + 16px 圆角 + 语义 token + 克制的柔和阴影 | 它的框架（本文件仍是零依赖纯 CSS） |
| designeer.xyz（用户补充） | 白画布、近黑正文、发丝线分隔、字号级差小 | **灰阶与呼吸感** | 它的画廊内容形态 |

一句话：**recapo 给结构、boardui 给零件、designeer 给灰阶，白底是用户拍板的。**

## 2. 具体改了什么

### 2.1 token：底色全白，灰阶重排

```
canvas #ffffff  bg #ffffff  card #ffffff  side #ffffff
line   #e6e8ec  hairline #f0f1f4  muted #f7f8fa
txt    #101114  sub #5b6068  sub2 #959ba4
pri    #e79379（未动）      acc  #bf6a50 → #a9553c
```

- **四个面全白**：画布 / 主区 / 卡片 / 侧栏。只改画布会留下「白纸上贴一块米色」的夹生状态。
- 白底上分层只能靠 1px 边框 + 主区的 16px 圆角，所以边长从 `#d6d0c2`（cream）换成 `#e6e8ec`。
- 圆角整体放大一档：`4/6/8/10` → `6/10/14/16`（对齐 boardui 的 `rounded-2xl`）。

### 2.2 主色对比度：白底上必须重算

| | 值 | 对白底 | 结论 |
|---|---|---|---|
| 旧 `--acc` | `#bf6a50` | **3.89:1** | 白底上不够 AA（cream 时代够用，改白后不够） |
| 新 `--acc` | `#a9553c` | **5.19:1** | 正文级 AA 达标 |

`--pri:#e79379` 保持不动，但它对白底只有 2.6:1 —— 所以它**只做浅底与描边**，实底一律用 `--acc`。
这条不是本轮新发明，v10.105/106 已经这么分工，本轮只是把 `--acc` 压到位。

### 2.3 页头：从「列表头」变成「页标题」

原来 `面包屑 + 标题` 挤在同一行，标题只能压在 14px —— 那是列表头的尺寸。现在：

```
内容 / 本体 · FITGIRL REPACK        ← 10.5px 大写字距，独占一行
资源管理 · 本体                      ← 19px / 650，负字距
```

去掉标题前那个假斜杠（面包屑已经表达了路径）。

### 2.4 面板：从「框」改回「分节」

白底上「框套框」会让边界互相打架：`侧栏框 + 主区框 + 面板框 + 表格框 + 统计卡框`。
所以 `.panel` 去掉 `background/border/radius`，改成「标题 + 发丝线 + 内容」的分节（recapo 那一层）：

```css
.panel{background:none;border:0;border-radius:0;margin-top:26px}
.panel .ph{border-bottom:1px solid var(--line);padding:0 0 9px}
.panel .pb{padding:14px 0 0}
```

### 2.5 侧栏：unicode 图标 → 矢量

`▦ ▤ ⛃ ◇ ≡ ⇩ ⚙` 七个字符在不同字体下粗细/基线都不同，一排看过去像拼凑的。
换成 1.7px 描边的 24 格 SVG，`stroke:currentColor` ⇒ 选中态自动跟主色走。

同一批还有一个隐形缺陷：仪表盘四张**模块卡**的头部直接渲染 `m.icon` 的 unicode 字符
（`⛃ ◈ ⚔ ▣`），在正文里掉成豆腐块。改成同一套矢量 + 浅底图标方块。

顺带修掉一个 v10.107 漏删的东西：侧栏出现过**两个「内容」分组标题**
（把四扇门收成一扇时只删了条目、没删分组标题）⇒ 现在是 `总览 / 内容 / 运维` 三组。

### 2.6 资料完整度：红墙改成迷你计量条

实测这页九成行都是 `2/7`，而旧逻辑 `comp<3 ⇒ b-hide`（红底）⇒ **整列一片红**，
读起来像「全表出错」，真正需要突出的低完整度反而不突出。

改成：`条长 = n/7` + 中性数字；只有 **0 项**才红，3-4 项琥珀，5+ 项绿。
`n/7` 这个口径和 `title` 都没变，只是表达方式从「涂色徽标」换成「计量条」。

### 2.7 白底上必须补的四个细节

- 弹窗遮罩加 `backdrop-filter:blur(3~4px)`（纯 38% 黑压在内容上会糊成一片）
- 滚动条收成细轨（默认浅灰实心块在长表格里非常扎眼）
- `:focus-visible` 给 2px 描边（键盘可达）
- 输入框焦圈 `rgba(231,147,121,.22)` → `.16`（22% 在白底上是一片粉雾）

## 4. 没做的事

- **没动主站**（`public/index.html` 及其四张派生页）。用户明确只要后台。
- **没引 Tailwind / React**。boardui 是 React+Tailwind 的源码分发型组件库，这里只搬形态，不搬依赖。
- **没改任何接口**，`/api/build` 里 admin.html 的 md5 会随载荷自然变化。
