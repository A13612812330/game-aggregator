# v10.84 —— 冷门游戏隐藏：库内保留、列表不显示（搜索可搜 / 详情可达）

> 用户拍板（2026-10-19）：「冷门游戏我们暂时先移除（放在游戏库，但是不显示）」。
> 口径经 AskUserQuestion 二选拍板：**hot=0 且非近 90 天新游**（热启动期保护）· **搜索可搜到**。

## 一、改了什么

| 文件 | 改动 |
|---|---|
| `data/cold-hide.js`（新） | 口径单一来源：`isCold / isHidden / stats` + 手工豁免通道（`data/hide-overrides.json`，可选文件，`show` 赢规则 / `hide` 强制藏）。**现算不落名单**——games.json 每日同步都在变（新游进 90 天窗口、热度更新脱离 hot=0），落文件必然漂移；现算 O(n) 毫秒级 |
| `data/gamesDb.js` | `applyOpts` 新增 `excludeCold` 钩子：**池前过滤**（排序/分页之前）——分页后过滤 = total 与条目错位 |
| `server.js` | 仅 `/api/library/browse` 开 `o.excludeCold`（scope=pc 与 scope=all 同钩子覆盖）；`?cold=0` 逃生口；新增 `GET /api/cold/stats` 自证端点 |
| `tools/test-cold-hide.js`（新） | 18 条防线，登记 run-all SUITES |

**没动的**（行为边界，有意为之）：`/api/search`、`/api/library?q=`（搜索可搜到）；`/api/library/item`、详情 merged（详情可达）；`/api/hots`、`/api/category`、`/api/feed`（源站实时镜像——冷门游戏本来就不在官网版面，语义上不该过滤）；`/roster` 看板（管理视角保持全量）；手游池 scope=mob（口径只对端游库）。

## 三、踩过的坑

- **口径数字会漂移**：拍板时引用的 8,556 是当日快照值；daily-sync 之后新游上架/热度更新都会变。防线因此**不写死数字**，套件内独立重算与 `coldHide.stats()` 夹逼比对（两边都现测，不许抄）。
- `/api/search` 是源站实时搜索、`/api/library?q=` 才是库内搜索——验证「可搜到」必须打对端点，打错端点会误判成「搜不到」。
