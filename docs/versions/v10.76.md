## ① ★★★ 「点击年度榜会有页变化」的根因：**状态行的高度由文案长度决定**

这是本轮**唯一一个必须量化才能定位**的问题，所以先做探针（`tools/_probe-v1076-layout.js`），
在 1440×1000 下逐档点击，记 `.stage-h` 高与「最新收录」top：

| 档 | `.stage-meta` 文案实测宽 | 能否挤进标题行 | `.stage-h` 实测高 | 「最新收录」top |
|---|---|---|---|---|
| `recent` | **158px** | ✅ 挤得下 | **46px** | **1258** |
| `hot` | **485px** | ❌ 换到第二行 | **85px** | **1297** |
| `month` | **592px** | ❌ 换到第二行 | **85px** | **1297** |
| `year` | **585px** | ❌ 换到第二行 | **85px** | **1297** |

⇒ **整页下移 39px**。改前 `.stage-meta` 是 `flex:none` —— 它**没有定宽，也没有定高**，
于是宽度**跟着文案走**：短文案（`recent` 的「XD 官网 · 最近更新 · 更新 19:27」）能与标题并存，
长文案（`month` 的「XD 月度 + 机地本月热榜 · 加权合并 · 更新 19:27」）挤不下就**换行**，
换行就**撑高**，撑高就把下面所有东西推下去。

★★ 关键认识：**这不是「哪个属性写错了」，而是「高度是一个自变量」**。
只要高度可以由外部数据（文案长度）决定，位移就一定回来 —— 换个文案更长的档还会再发生一次。

### 修法：三道缺一不可

```css
.stage-meta{...; flex:0 0 100%; height:24px; overflow:hidden}      /* ① 位置 ② 行数 */
#rankMeta{flex:1; min-width:0; white-space:nowrap; overflow:hidden; text-overflow:ellipsis}  /* ③ 行长 */
```

| 道 | 属性 | 定住的是 | 缺了会怎样 |
|---|---|---|---|
| ① | `flex:0 0 100%` | **位置**（状态行独占一行，不再与标题抢位） | 文案短时又跑回标题行 ⇒ 高度在 46 / 85 之间跳 |
| ② | `height:24px` | **行数**（不管文案多长都是 1 行） | 长文案换行 ⇒ 撑成 2 行 |
| ③ | `nowrap` + `ellipsis` | **行长**（长文案只截**显示**，不撑容器） | 定高 + 溢出可见 ⇒ 文案压到下一块上 |

★ 只做 ①② 不做 ③：容器定高 24px，但文字**溢出到外面**（`overflow:hidden` 必须有）。
★ 只做 ①③ 不做 ②：位置对了，但 `height` 仍由内容决定 ⇒ 字体/断点一变就漂。
★ 只截**显示**不截**信息**：状态行全文挂 `title`（D20c 守着）——
「把文案删光」也能让高度恒定，所以必须有「信息还在」的正向断言。

**修后实测**：`.stage-h` 四档 **84 / 84 / 84 / 84**，「最新收录」top 四档 **1367 / 1367 / 1367 / 1367**，
轮播 top 与高 **168 / 379** 四档全等，`docH` **4110** 四档全等，切档过程 `scrollY` **全为 0**。
四档头部元素实拍尺寸 **1196 × 84.39**（四张 `head-*.png` 逐张量过）。

## ② ★★ 「轮播图太大」= 559px 高，而**限宽不能限高**

改前（v10.75）轮播在桌面 1440 下是 **1196 × 559** —— 它通栏，且按 `--cover-ar`（460/215 ≈ 2.14）算出 559px 高。

**第一个念头是「限高」**，但这**直接踩中 v10.75 刚记下的铁律 123**：
`aspect-ratio` 与确定 `height` 并存时，`width` 会被 `height × ratio` **反算**出来 ——
限高不是「变矮」，是「连宽度一起被压窄」。所以**只有限宽一条路**：

```css
:root{ --car-max-w:810px }
.rk-car{width:min(100%,var(--car-max-w));aspect-ratio:var(--cover-ar);margin:0 auto 12px}
```

| 断点 | 容器内容区宽 | 轮播实测 | 说明 |
|---|---|---|---|
| 桌面 1440 | 1196 | **810 × 379** | 上限生效，左右各留白 **193**（居中） |
| 移动 390 | 350 | **350 × 164** | `min(100%,810px)` 落到 `100%` ⇒ **自动撑满** |

★★ **`min(100%, X)` 让窄屏自动退化成「打满」，不需要写任何媒体查询** ——
这比「在断点里改数字」少一个漂移点。★ 反过来说，**判据也必须分档**：
第一版 P14 写「轮播必须比内容区窄 40px」，在 390 视口必然假红（350 < 310 不成立）——
那是**把拍板目标当成了全局等式**（见 ⑥ 坑 4）。

## ④ ★★ P17 照出一个真缺陷：**骨架高度是一个内联字面值 ⇒ 必然只对一侧**

这是本轮**唯一由防线主动抓出来的缺陷**（不是用户报的、也不是我看代码看出来的）。

`.rk-skel-card .sk-tx`（骨架的文字区高度）原来写在 `rankSkeleton()` 里，
是一个**内联字面值 66px**。而真卡的 `.bd` 在移动端**有自己的内边距 / 字号覆盖** ⇒ 实测：

| 断点 | 真卡 `.bd` 实测高 | 骨架字面值 | 差 |
|---|---|---|---|
| 桌面 | **65.61px** | 66px | ✅ 对上 |
| 移动 | **61px** | 66px | ❌ **差 5px** |

⇒ 移动端「骨架 → 真卡」会跳一下。**根因不是数值写错，是「一个值服务两个断点」这件事本身错了**。

修法：改成 **CSS 类 + 两处断点**（单一真源）：

```css
.rk-skel-card .sk-tx{height:66px; ...}
@media (max-width:760px){ .rk-skel-card .sk-tx{height:61px} }
```

### ★★ 判据必须**跨层**，否则守不住

守「骨架高 = 真卡高」这件事，**不能只看源码**（源码只有字面值，没有真卡），也不能**只看渲染**
（渲染期没有骨架，骨架在加载中就已经被替换掉了）。所以 P17 的做法是**读主源文本里的字面值**，
与**浏览器实测的 `.bd` 高**作差，按断点取第 1 / 第 2 个值，差 ≤ 2px。
这样「改了 CSS 忘了改骨架」两件事都会红。

★ 对应反证 ⑰ = 删掉移动端那处断点覆盖 ⇒ D16 红。

## ⑤ ★★ 三处「一侧源站挂了会拖住整个接口」的连锁修复

本轮把服务端从「能返回」推到「**挂得不难看**」。三项，都是实测逼出来的：

| # | 现象（实测） | 根因 | 修法 |
|---|---|---|---|
| 1 | 首调时机地侧偶发失败 ⇒ 融合退化成仅 XD，而 **30 分钟 TTL 把降级钉死**（连打三次 `refresh=1` 才恢复 `jidiN=12`） | `cached()` 只支持固定 TTL，降级结果与正常结果**共用同一个 TTL** | `cached()` 支持**函数 TTL**；`/api/rank` 在降级时只缓存 **120s**，正常 **1800s** |
| 2 | 点人气榜后 **2.6s 状态行还停在上一档** | `getHtml` 是 `timeout 20s × (1+1 重试)` ⇒ 最坏 **40s**（v10.75 就有，未暴露） | `Promise.allSettled` 等最慢的一侧 ⇒ 机地侧包 `withTimeout(jidi.hotRanks(), 6000, '机地热榜')` |
| 3 | 机地挂了，该档静态口径仍写「XD 人气 + 机地本周热榜 · 加权合并」 | 文案是**静态口径**，不知道本次跑成什么样 | 前端记 `rankSrcOk[档]`，降级时文案追加「**· ⚠️ 机地源暂不可用，本档已降级为 XD 单源**」 |

★★ **降级的判据必须带 `RANK_JIDI_KEY[p]`**：`recent` 档**本来就不抓机地** ⇒ 它的
`meta.jidiOk` **天然是 false**，只看 `jidiOk === false` 会把正常档误判成降级（D15 守这条）。
★ 反证 ⑱ = 删掉降级播报 ⇒ D21 红（**用户拍板口径里没有「静默降级」这一项**）。

★★ **`withTimeout` 必须给内层 promise 挂拒绝处理**：

```js
p.then((v) => { clearTimeout(t); resolve(v); },
       (e) => { clearTimeout(t); reject(e); });   /* ← 没有这一路，Node 22 崩进程 */
```

因为 `Promise.allSettled` 拿到的是**外层 race**，内层 rejection **无人处理** ⇒
unhandledRejection ⇒ **整个服务进程退出**。D17 一开始写成
`/p\.then\(\s*\r?\n?\s*\(v\) =>/`（只判形状）—— 反证把两参 then 换成单参**照样匹配**（假绿），
改判**拒绝处理那一路**才拦得住（见 ⑥ 坑 5）。

### ★ 收尾实测的一个反转：机地现在是**快速失败**，6s 硬超时**本轮并未被触发**

改完之后重新计三档接口耗时（`refresh=1`，现测）：

| 档 | HTTP | 耗时 | `jidiOk` | `xdN` | `jidiN` |
|---|---|---|---|---|---|
| `hot` | 200 | **692 ms** | false | 99 | 0 |
| `month` | 200 | **608 ms** | false | 100 | 0 |
| `year` | 200 | **586 ms** | false | 100 | 0 |

⇒ 上游不是「挂住不动」，而是**很快返回那个 23,670 字节的挑战页**、解析立刻失败。
所以 `withTimeout(…, 6000)` **本轮一次都没被触发**。

★★ 这一点必须如实写清，否则会让人以为「超时逻辑已经验证过有效」：
**它守的是「将来某次真的挂住」，不是现在这个故障形态。**

**(b)** 四档几何仍然全等（`month` / `year` 的文案比 `hot` 长 **40 多个字符**，`.stage-h` 仍是 **84px**）。
★ 换句话说：**「文案变长会不会撑高」这件事，本轮恰好被「降级播报」这句新文案真实压测到了** ——
这也是四张 `head-*.png` 值得留档的原因。

## ⑦ ★★ 机地上游被阿里云 WAF 拦住（**本轮实测，与本次改动无关**）

定位 dlstrip 那套「整套崩」时抓到的，顺带解释了 merge 的 2 条红：

| 探测 | 结果 |
|---|---|
| `jidiyouxi.com` 的 `/`、`/topic/`、`/topic/detail/*` 纯 HTTP | **10 / 10** 返回 **23,670 字节**的 JS 挑战页（`aliyun_waf` / `aliyunwaf_*`，**无 `appState`**） |
| 同一 URL 走真浏览器（CDP） | **6.1s** 拿到 **1,393,311 字节**真实页，`#appState` **存在** |

⇒ 机地**需要浏览器关口，纯 fetch 过不去**。连带后果（全部实测）：

- `hotRanks()` 抛「机地热榜页解析失败」⇒ `jidiOk=false / jidiN=0 / dualN=0` ⇒「双源加权合并」**静默退化成单源**；
- `/api/detail/merged?url=<机地话题页>` 返回 **502**，响应体
  `{"ok":false,"error":"机地详情页未内嵌数据（可能改版）: …"}` ⇒ 机地游戏的详情页**整页打不开**。

★★ 这一条**不是本轮引入的**，且**本轮已把它从「静默」变成「可见」**（降级播报 + 6s 硬超时 + 降级短缓存）。
但它同时暴露一个**新的、未修的韧性缺口**：**机地链路挂掉时详情页是 502，而不是「退回单源」**（见 ⑨）。

### ★★ 连带的防线影响：**四套联网套件的样例都指向「艾尔登法环」这一条机地条目**

定位那几套红时，直接调接口取证（不是猜）：

```js
GET /api/library?q=艾尔登   → {"url":"https://jidiyouxi.com/topic/detail/3279789","title":"艾尔登法环","source":"jidi"}
GET /api/detail/merged?url=<上>  → 502 {"ok":false,"error":"机地详情页未内嵌数据（可能改版）: …"}
```

⇒ `test-v1025-gallery`（找 `.gal` 画廊）与 `test-v1025-search`（找抽屉标题）**取的是同一条样例**，
而这条样例的详情页**根本打不开** ⇒ 两套一起红。`test-v1025-dlstrip` 的样例也是机地条目
（`jidi-3277800` 赛博朋克2077，`/api/detail/merged` 同样 502），所以它会以「整套崩（`no #dlStrip`）」
或「41/41 通过」两种形态出现。`test-v1025-merge` 的 2 条红则是直接抓机地页面。
⇒ **四套的红是同源，且都指向「机地详情页/话题页不可达」**（新增铁律 138）。

## ⑩ 本版一句话总结

**用户报的「点击年度榜会有页变化」不是一个样式 bug，是「高度成了自变量」** ——
状态行的高度由文案长度决定，只要这个依赖存在，位移就一定会以别的形式回来。
所以修法不是「把状态行调窄一点」，而是**把位置、行数、行长三件事各自钉死**。
而「轮播太大」这条，真正的收获是**否掉了第一直觉**：在 `aspect-ratio` 下**限高会反算宽度**，
想变矮只能**限宽** —— 顺带用一个 `min(100%, X)` 把窄屏适配也免掉了。
