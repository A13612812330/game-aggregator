# v10.82（2026-10-16）— 修复：解包匹配 / 解压助手页「🏠 首页」点了无效

> 起点（用户原话）：「发现个bug，在解包匹配和解压助手点击首页都无效」。

## 一、根因（一句话）

**两个页面的构建脚本漏了 `body[data-page]` 标记**，首页脚本用 `IS_SUB_PAGE`
（`document.body.getAttribute('data-page') !== ''`）区分两种语义：

| 页面 | body 标记 | 点「🏠 首页」的实际行为 | 用户看到 |
|---|---|---|---|
| 主源 index.html | 无（首页） | `preventDefault()` + 平滑回顶部 | 正常（回顶部） |
| emulator.html | `data-page="emulator"` | 交回 `href="/"` 真跳转 | 正常 |
| resources.html | `data-page="resources"` | 同上 | 正常 |
| **unpack.html** | **裸 `<body>`（漏标）** | **被拦成回顶部** | **「点了无效」** |
| **extract.html** | **裸 `<body>`（漏标）** | **同上** | **「点了无效」** |

即：漏标 ⇒ `IS_SUB_PAGE=false` ⇒ 拦截默认行为改做「回顶部」——已在顶部时看起来就是毫无反应。

- 这套机制是 **v10.44** 建的（判据当时已放宽为「任何带 data-page 的都不是首页」），
  但 emulator / resources 是带标记上线的老页，**v10.71 拆出 unpack / extract 两个新构建脚本时没把标记带上**。
- 底部 Tab 的「首页」（`aria-label="首页"`，同样 `href="/"`）**不受影响**——那段没有点击拦截；
  用户报的「无效」是顶栏 `#navHome`。

## 二、改法（全在构建源头，不改主源）

| 文件 | 改动 |
|---|---|
| `tools/build-unpack-page.js` | `'<body>'` → `'<body data-page="unpack">'`（附根因注释） |
| `tools/build-extract-page.js` | `'<body>'` → `'<body data-page="extract">'`（同上） |
| `public/unpack.html` / `public/extract.html` | 重跑两个 builder 重建（465.3 KB / 468.6 KB） |
| `tools/test-pages-sync.js` | **新增回归断言**：五张派生页逐一要求 `<body …>` 带 `data-page`（54→58 条） |

主源 `index.html`、`server.js`、`data/**` 均**未动** ⇒ 不触发「重建四张派生页 / 重启服务」铁律
（unpack / extract 两张已按需重建）。

## 三、验证（全绿）

| 防线 | 结果 |
|---|---|
| `test-pages-sync.js`（含新断言） | **58/58** |
| `test-twin.js` | 69/69 |
| `test-card-parity.js` | 69/69 |
| `test-v1071-extract-page.js` | 24/24 |
| **真浏览器探针 `_probe-v1082-navhome.js`（CDP，本地 8124）** | **6/6** |

探针判据（不只是看标记，**真点**）：
1. unpack.html 标记 = `unpack`，点 `#navHome` → URL 变 `/`（真跳转）✅
2. extract.html 标记 = `extract`，点 `#navHome` → URL 变 `/` ✅
3. **反证**：首页 body 无标记，点 `#navHome` → 仍在 `/`（回顶部语义未破坏）✅

## 四、铁律 150

> ★ **派生页的 body 必须带 `data-page` 标记**（v10.82 实测）：主源脚本用 `IS_SUB_PAGE`
> 区分「首页=回顶部 / 子页=真跳转」。新拆派生页时漏标 ⇒ 顶栏「🏠 首页」被
> `preventDefault` 拦成回顶部，**症状是「点了没反应」而不是报错**。
> 防线：test-pages-sync 对全部派生页断言 `<body … data-page>`，新页登记 PAGES 即自动覆盖。
