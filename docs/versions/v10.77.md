`width:min(100%,`）＋ 浏览器层 P14（正向：轮播宽 == 内容区宽，左右留白 ≤ 2px）。

## ② 卡片 5 列 × 3 行 = 15：「每一行都铺满」的落地

用户给了参考截图（桌面 5 列）并点名「**每一行都铺满而不是遗漏（三行）**」。

- `data/rank-fill.js`：`RANK_SHOW_N` **14 → 20**（轮播 5 + 卡片 15），一处定义、服务端 meta 下发。
- 前端 `RK_CARD_N` 9 → **15**；`.rk-grid` 桌面 `repeat(5,minmax(0,1fr))`。
- **窄屏 2 列 × 3 行 = 6**（用户拍板）：多出的 9 张由 CSS `nth-child(n+7)` **隐藏** ——
  条数池是桌面口径，前端只拿一份 list，窄屏收可见数只能在 CSS 层做。
  ★ 隐藏规则同时覆盖 `.rk-skel-card`（只藏真卡会让加载态露出 4 个孤零零的骨架格）。
- 「铺满」的可测形式（浏览器层 P6b）：**按 top 分组数每行卡片数，每行必须 == 列数**
  （桌面实测 `[5,5,5]`、窄屏 `[2,2,2]`）。⚠️ 单看「行数 == 3」照不出 `[5,5,4]` 末行缺一张 ——
  行数不变、任何比例判据也照不出，必须有这条**逐行**判据。

## ③ 信息行加日期：三项 = 类型 · 大小 · 日期

- 渲染：`<span class="dt">🕐2026/08/12</span>`（`dateLabel` 的 `-` 换 `/`）。
- ★★ **不许写死中文语义标签** —— 实测 `/api/rank?p=hot`：XD `/update/` 侧的 `dateLabel`
  是**更新日期**（recent 第 1 条 = 当天），机地热榜侧是**发行日期**。写死「发行日期」
  在 XD 档就是失实。所以只允许「图标 + 值」，静态层 D23 守（见 ⑤-1）。
- 缺项不塌行：`size=null` 的条目（如「黑森林迷踪」）该项省略，`.s` 有 `min-height` 底高。
- 信息行会**换行**（卡宽窄于临界时三项装不下）⇒ `flex-wrap:wrap` + `min-height` 分档
  （桌面 22 / 平板 46 / 移动 45，均为实测）。**换行临界实测夹在 1100 / 1110px 之间**
  （内容宽 180 换行、182 单行）⇒ 骨架断点落 1100px。

## ⑤ 踩过的坑（三条都是这一轮真实发生）

### ⑤-1 D23 连红两次，两次都是**作用域**问题

- 第一版负向判据跑在**未剥注释**的 `idx` 上 ⇒ 被解释这条口径的注释骗（铁律 126）；
- 第二版跑到 `idxC` **仍红** —— 因为**详情页实现里「发行日期 / 更新日期」是合法的**
  （`d.releaseDate` 是真发行日期），整份文件级的负向判据天然假红。
- ⇒ 必须**收窄到目标段**：只看 `rankCard` 函数体（铁律 81：作用域既会假红也会假绿）。
  一个断言连踩两条老坑，充分说明「判据的作用域」和「判据的内容」同等重要。

### ⑤-2 隐藏容器里的 `<img>` 不触发 load ⇒ CDP 挂死 180s

窄屏 `nth-child(n+7)` 上线后，测试里「等全部榜单图 onload/onerror」的 promise
**永远 pending**（display:none 容器的 img 不触发 load/error）⇒ CDP `callFunctionOn`
等到 protocolTimeout（180s）才炸，症状是 `FATAL ProtocolError`，一次 3m9s 才暴露。
⇒ 等待与 P2 破图判据都改**只针对可见图**（隐藏卡的图不是用户看到的）。

### ⑤-3 隐藏卡 rect 全 0，把行统计数炸了

窄屏 `rowN` 判成 4、`lineCounts = [2,2,2,9]` —— 9 张隐藏卡的 `top` 全是 0，被当成第 4 行。
⇒ 几何统计一律先过滤可见卡（`width>0 && height>0`）；`cardN`（池子总数）仍取全量。

### ⑤-4 反证锚点被 CRLF 骗

新反证 ㉒ 的字面锚点里写了 `\n`，主源是 CRLF ⇒ 永远不命中，反证预检报「锚点没命中」。
⇒ 含换行的锚点用正则 `/\r?\n/`。另 ⑰ 的锚点（骨架移动端值）跟着 61 → 84 改。
