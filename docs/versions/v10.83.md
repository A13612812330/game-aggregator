## 三、Modrinth 为什么撤下（实测记录）

1. **不支持按游戏过滤**：`games:<slug>` facet 实测 0 命中（连 minecraft 都是 0）⇒ 只能名称搜索。
2. **模糊搜索的描述命中全是假亲**：query=raft 第一名是 MC 模组 Blazing Bamboo（描述含 "lava rafts"）；
   无护栏首抓 58 游戏 / 241 包，人工核验**全部是 MC 模组**（valheim 命中的《Spice of Life: Valheim Edition》也是 MC 模组）。
3. **双护栏重抓 = 0**：名字护栏（slug/title 必须含查询词）+ loader 护栏（纯 fabric/forge 等剔除）⇒ 252 游戏全 0。
4. 处置：server `/api/mx/mods`、前端第五路、`data/modrinth.js` 全部回滚；探针留档
   `tools/fetch-modrinth.js`（带双护栏与结论头注）；test-v1083 防回归断言禁止悄悄复活。⇒ 铁律 151。
