## 一、做了什么

### P0 落库（`data/fitgirl.json` + `tools/gen-fitgirl.js`）

| 项 | 数字（现测） |
|---|---|
| FitGirl 目录快照 | 8,114 帖（WP REST API 82 页，2026-10-19 抓取） |
| 本体库 | 19,695 条（可匹配 18,917） |
| **命中游戏** | **5,811**（entry 5,813；exact 跨段全收集 + prefix 首个） |
| adult 命中 | 2 款（标题关键词 + VETO 名单 `tropical-lust`） |
| 产物体积 | 1.26 MB |

- **结构**：`byGame[游戏库 id] = [{ source:'fitgirl', slug, url, title, date, adult }]`，新帖在前。
  **多源 repacks[] 设计**：后续 DODI/ElAmigos 接入只加采集器不改结构（P2 预留）。
- **匹配逻辑**：`_probe-fg-match.js` 最终版原样移植（五道护栏：分段 / 剥尾 / 续作护栏 /
  点号缩写 / 罗马归一）。**为什么重跑而不读探针明细**：探针产物只存样例
  （hitSample 15 / missSample 40），不是全量映射 ⇒ 铁律 155。
- magnet **不进快照**：目录 82 页是轻量字段（content 拉全量曾撑截断 6 页），
  正文里的 magnet 只能单篇按需抓。
- 刷新方式：目录更新 → 重抓快照（WP REST 循环）→ 重跑 `node tools/gen-fitgirl.js`；
  daily-sync 新增游戏重跑生成器即可补匹配（当前未挂 daily-sync，防同步套件联动）。

### P1 服务端（`server.js` + `data/fitgirl.js`）

- `GET /api/fitgirl/repacks?id=&t=`：详情页外链档数据；`?t=` 兜底走 gamesDb 一跳解析
  （同 `/api/ts/mods` 形态，修过的那个 search().items）。
- `GET /api/fitgirl/magnet?slug=`：**按需现抓单篇**提 magnet，`.cache/fitgirl/<slug>.json`
  **TTL 24h**（防 FitGirl 限速；repack 页 stable）。
  - ★ SSRF 白名单：slug 必须 `/^[a-z0-9-]+$/` **且在 fitgirl.json 表内**（URL 只由自家数据拼）。
  - ★ 实测坑：页面里 `&` 有 **`&amp;` 与 `&#038;` 两种转义形态**，只还原前者会产出坏磁力
    （首抓现照：`btih:D9A8…&#038;dn=`）。
  - 返回最多 5 条，第一条 = FitGirl 官方种子（tracker 最多、含 Selective Download）。
- **不做流代理**：filehoster 有 CF 挑战/reCAPTCHA 中转页，服务端复刻不可行（v10.81 调研终局）。

### P1 前端（`public/index.html`，四张派生页随建）

- 本体页签新增 **FitGirl Repack 段**（`.dl-gcm` 容器，与修改器 GCM 段同一行样式，铁律 17）：
  - 「↗ 打开 Repack 页」：`ext:true` 新标签直开原站文章页，零直链维护；
  - 「⧉ 复制磁力」：fetch magnet 端点 → clipboard；**剪贴板不可用降级 `window.prompt` 手动复制**
    （不静默失效）；按钮态反馈（… 抓取中 / ✓ 已复制 / ✗ 原因）；
  - adult 条目**照样显示**（详情页要能获取 —— 用户口径），带 18+ 角标；
    列表层不铺 repack 条目，无列表过滤问题。
- **接线**：`dlUniLoad` body 分支 `Promise.all([dlUniFetchBody, dlUniFetchFg.catch(→null)])`
  并行取（本地索引毫秒级，不拖慢 302 解析；失败静默 = 段不出现）；
  `dlUniPane` 在 `dlUniPaintBody(d)` **之后** `dlUniPaintFg(st.data.fg)` ——
  追加而非内嵌，`paintDownload()` 一行不动；**noSrc / 全空态路径 FitGirl 段照样出现**
  （网盘解析失败时它往往是唯一第二出口）。
- 与自研下载器（P3）的接口约定：P3 上线后只把「复制磁力」升级为「用 GameHub 下载器下载」
  （本地端口探测/自定义协议），失败落回复制磁力 —— 本段与服务端端点不动。
