## 五、踩过的坑

1. **驱动脚本的注释里不能出现 script 标签字面量。**
   `tools/resource-sections.js` 头部注释写了 `<script>`，语法闸按字面量数块数 ⇒ resources.html 被算成「2 个 script 块」。
   与「模板串里不能写反引号」「块注释里不能出现闭合序列」同源：**分隔符本身不能出现在内容里**。

2. **`Write` 工具拒绝写「未读过」的文件。**
   `build-resource-page.js` 是用 `cp` 复制来的副本，直接覆盖被拒 ⇒ 先 `Read` 一次再写。

3. **反证的变异不够窄 ⇒ 抓住它的不是要守的判据。**
   类名隔离那条判据第一版写成字符串前缀 `/!<button class="emu-tab/`，
   变异「把 `.emu-tab` **追加**到类名尾部」**两条都没红**（页签计数也不变）——
   说明这条判据根本抓不住。改成按**类名 token** 判之后才被抓住。
   > 这是反证最大的价值：不是「验证判据生效」，而是**发现判据写错了**。

4. **搬家的默认口径容易漏。**
   存档在手机专区语境默认「仅看手机能玩」；搬到端游资源语境后默认改为**全量**。
   漏掉就会出现「代码搬了、默认只给 1/6（1,163 / 6,625）」，页面上完全看不出异常 ⇒ 已单列一条断言钉住。

5. **`.paths` CSS 的 grep 假警报。**
   规则体跨行，`grep -o '.emu-card .paths{[^}]*}'` 匹配不到，一度以为样式没搬过来；用 node 按整串匹配确认两页都在（9 条规则齐全）。**判据别用行式 grep 查跨行 CSS。**
