## ⑥ 新坑（铁律 145）

**gen 模板串里的 `\n` 会被提前转义成真实换行，把产物里的字符串字面量劈成跨行 ⇒ 整页 JS `SyntaxError`。**
本轮 `tsvOf` 的 `join('\n')` 在 gen 的反引号模板里写，产物变成 `join('` + **真实 LF** + `')` ——
页面全部脚本瘫痪（表格/弹窗/分析全死），而 `node --check tools/gen-roster.js` **查不到**（它只查 gen 自身，
内嵌 JS 是字符串内容）。修复：模板串内一律写 `\\t`/`\\n`；防线 **J12** 用 `vm.Script` 逐段解析产物
`<script>`，这类事故以后**出页即红**。同坑变体：注释里写 `\n` 同样被转义（只是把注释劈开，无害但难看）。
