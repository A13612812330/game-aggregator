- 令牌真源：`env GAMEHUB_ADMIN_TOKEN` > `data/admin-token.json`（48 位 hex 随机生成，
  `.gitignore` 不入库、随发布载荷上线）。每请求现读文件 ⇒ 改令牌不用重启。
- `adminLocalOnly` 函数**保留**（test-roster J15.4 断言依赖 + 回环语义不变），
  写端点全部切到 `adminGuard`（双轨）。

## 二、`/admin` 详细管理后台（public/admin.html，独立页非派生页）

- **统计卡**：`GET /api/admin/overview` 一发拿全 —— 冷门口径（总数/可见/隐藏/热启动保护/豁免）
  + 库构成（双源覆盖）+ 六源 stats（mods/trainers/saves/gt/fitgirl/tsmods）。
- **列表**：`/api/library/browse?scope=pc&cold=0&admin=1`（管理视角全量池）。
  - `admin=1` → 每行服务端回填 `hidden`/`cold` 布尔（铁律 154：判定不靠前端猜）；
  - `hidden=1|0` → **池前过滤**（`o.filter` 走 `coldHide.isHidden` 同一真源，total 与行数一致）；
  - `/api/library?q=&admin=1` 搜索模式同样回填；
  - 筛选：隐藏态 / 📖MOD / 🛠修改器 / 💾存档 / 排序五档 / 分页。
- **详情抽屉**：`GET /api/admin/game?id=` 一发聚合**七路资源** ——
  机地帖三分类（resGroups，孪生兜底走 `resFor` 与首页 chip 同源）· FLiNG/TCS 修改器（挂流代理/外链）
  · 云存档（savesYx）· GTrainers · FitGirl（含 18+ 标记）· Thunderstore；
  附隐藏态三问（规则/最终/豁免）+ resId + 操作按钮。
- **豁免操作**：隐藏/显示/清除 → `POST /api/admin/hide-overrides`（即时生效，与 v10.85 同一 coldHide 真源）。
- **操作日志**：`data/admin-log.jsonl` 追加（一行一条 JSON），`GET /api/admin/log?limit=` 尾读；
  记录 ts/id/title/op/结果/via（loopback|token）。写失败不阻断主流程。

## 五、本轮踩坑（两处旧防线字面量判据被合法演进打破）

1. **`o.excludeCold === false` 撞旧正则**：test-cold-hide 用 `o.excludeCold\s*=` 计数
   「赋值只此一处」，`===` 里的 `=` 被误计 ⇒ 条件改写 `!o.excludeCold` 避开。
2. **`map(withRes)` 字面量判据**：test-emulator-structure / test-v1062 钉死
   `items: r.items.map(withRes)`；v10.87 合法换成带标注的包装 map。按「判据钉意图」原则
   更新两条断言（包装内 `withRes(x)` 同样算挂），并在注释里写明 v10.87 变更。
3. **express.static 只认精确路径**：`/admin/` 会找 `admin/index.html` ⇒ 404；
   显式路由 `app.get(['/admin','/admin/'])` → sendFile admin.html。
