# v10.101 磁力点击唤起本机工具（协议 + 失焦判定，未单独发版）

> 这一版**没有部署到线上**。它的代码作为降级路径留在 v10.102 里，这里只做留档，
> 避免版本号断档、也避免以后有人问「失焦判定那段注释是谁写的、为什么留着」。

## 用户原话

> 「有没有办法就是点击后磁力下载判断，是否有安装我的那个磁力下载工具，如果没有则自动拉起工具下载，如果有则拉起我的工具进行下载」

## 做了什么

1. 新增 `KC_SCHEME='komoconvert://add?uri='`、`KC_SETUP`、`KC_WAIT_MS=2200`、`KC_DESKTOP`
2. `kcLaunch(magnet)` —— 用**隐藏 iframe** 加载协议（不用 `location.href`：未注册时会留下一条
   「无法打开」的跳转失败），同时监听 `blur` 与 `visibilitychange`，2.2 秒内失焦即判为「已唤起」
3. `kcTryHandoff(slug)` —— 取磁力 → 唤起 → 成功返回 true，失败返回 false 交给云下载
4. 云下载加载态补 Komo Convert 安装入口（放本站 `/dl/`，不放 GitHub Release）

## 为什么后来被取代

浏览器**没有任何 API** 能读「某协议是否已注册」，所以这一版本质是「试一次 + 用失焦反推」。
用户当时恰好切了窗口 → 误判成功 → 工具没起来、云下载也没弹，等于点了没反应。
v10.102 改成先探本机 aria2 RPC：探到就是装了，不需要猜。

**协议唤起这条路径仍然保留**（v10.102 的第二级），因为「工具装了但没常驻」的用户只能靠它。
