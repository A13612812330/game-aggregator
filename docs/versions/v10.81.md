# v10.81（2026-10-15）— 资源直链改造：修改器 / 存档 / MOD 三线「直链下载」

> 起点（用户原话）：「修改器，Mod，存档有没有办法通过反编译或者爬虫，获取对应平台的源文件，
> 后续直接通过链接下载本体，而不是通过网盘等进行爬取」—— 拍板 **P0→P1→P2 全做**。

## 〇、先回答「反编译行不行」

**反编译只能拿到接口，拿不到文件。** 机地 MOD/存档帖是用户上传的**网盘分享**
（实测 mods.json 8,943 条 100% 指向机地帖、内容全是夸克/百度口令）—— 文件本体在
夸克/百度服务器上，机地自己都没存。直链成立的唯一前提 = **平台自己托管文件**。
⇒ 正确路线不是「从网盘源挖直链」，而是「换自托管源」。三类资源都有自托管源：

| 资源 | 自托管直链源 | 本轮状态 |
|---|---|---|
| 修改器 | GTrainers（v10.47 已在库 9,346 条）+ **FLiNG 官网** | P1 新抓 1,161 页 |
| 存档 | 游侠补丁网（v10.46 已在库 2,043 条真直链）+ GTrainers saves | 早已接线（v10.53），本轮修端点 bug |
| MOD | **Thunderstore**（门 1，官方 CDN） | P2 新补源 254 社区 |
| （参考）本体 | XD 下载按钮实测也是网盘矩阵，连源站都不自托管 | 无源可换，维持现状 |

## 二、P1：FLiNG 修改器直链（新增 975 页 · 1,726 条直链）

- 链路（全部实测）：详情页 `/trainer/<slug>/` → `/downloads/<token>` → 302 Location 的
  `path` 参数 → **zip 直链** `wp-content/uploads/<Y>/<M>/<Name>.zip`。
- **防盗链**：直链无 Referer 403（`application/x-msdownload` 探到 200 需带 Referer）
  ⇒ 浏览器从本站点过去必被拦 ⇒ 新增**流代理** `GET /api/dl/fling?u=…`
  （服务端带 Referer 取流回传；SSRF 白名单：路径锁 `/wp-content/uploads/`，
  完整 URL 只认 flingtrainer 域；上游 hard timeout 30s + reader.closed 拒绝处理）。
- **死 token**：源站存在 302 → `path=/wp-content/uploads/`（空路径）的 token ⇒ 按
  `\.(zip|rar|exe)$` 过滤，空文件名不落库。
- **fling_archive 直链**：393 条的 officialUrl **本身就是** `archive.flingtrainer.com/files/*.rar`
  直链，免抓详情直接登记；流代理白名单放行该域。
- 产出 `data/fling-dl.json`：1,161 页 · withDl 975（84.0%）· noDl 180 · err 6 · **直链 1,726 条**。
- 前端「修改器」页签 GCM 段分治：有直链的条目渲染 `⬇ FLiNG ↗` 按钮（走流代理），
  文案从「一律不含下载地址」改为「其中 N 个风灵月影（FLiNG）官方文件可直下」。

## 三、P2：Thunderstore MOD 直链（门 1，252 款游戏 · 2,870 个包）

- 端点（全部实测）：社区清单 `/api/experimental/community/`（100/页 cursor）→
  匹配库内端游 → 包列表 `/api/cyberstorm/listing/<社区>/?ordering=most-downloaded&page=N`
  （20/页，**不含版本号**）→ 包详情 `/api/experimental/package/<ns>/<name>/` →
  `latest.download_url`（302 → `ccdn.thunderstore.io/...zip`，**无防盗链**，前端可直接 `<a href>`）。
  ★ 禁用的 `/c/<c>/api/v1/package/` 全量端点未使用（门 1 铁律）。
- **匹配口径（宁缺毋滥）**：社区名归一化后与库内英文段**精确相等**才建关联
  （343 社区 → 命中 254，误配 0），另配 20 条热门游戏别名表兜底。
- 产出 `data/thunderstore.json`：252 款游戏（2 款社区无包）· **2,870 个包** · 每 ≤20 个最热。
- 前端「Mod」页签第四路：`dlUniFetchTs`（失败返回 [] 不拖垮整页）→ TS 段
  （徽标 `TS`，排在机地帖**之前** —— 能直下的排前面）+ 角标计数 + 空态守卫
  （机地没有但 TS/GT 有时不再说「没有收录」，v10.53 同坑）。

## 四、顺带修的第二个真 bug

`ctx.title` 尚未解析（body 页签稍后才解析）⇒ GCM 段空 ⇒ FLiNG 按钮跟着消失。
行为探针实拍踩到（假绿链：弹窗开、hint 在、按钮无）。修复：id+t 双发。
