# v10.50 —— 卡片游戏名拆「中文名 + 灰字英文名」+ 原贴内容弹窗

> **一句话结论**：资源页卡片的游戏名从库名原串（`中文名/英文名/标签` 拼串）改成
> **中文展示名 + 下方灰字英文名**；有正文的条目多一个「原贴」入口（按钮 + 整行可点），
> 点开是 `#postPop` 弹窗 —— 标题 / 作者 / 时间 / 正文 / 步骤 / 截图，
> 正文用 `white-space:pre-wrap` **按原贴布局**铺开。数据全部来自本地既有字段，未新增任何抓取。

## 二、根因与数据（全部实测）

### ① 「游戏名导致卡片被撑高」

端游库 `title` 是 `中文名/英文名/标签` 用 `/` 直接拼的一长串：

```
赛博朋克2077/Cyberpunk 2077
星露谷物语/Stardew Valley/支持网络联机
料理模拟器/烹饪模拟器/Cooking Simulator          ← 中文别名可以有多个
上古卷轴5：周年纪念版/上古卷轴5：天际10周年重制版/The Elder Scrolls V: Skyrim Special Edition
```

铺到卡面 ⇒ 标题折 2~3 行、卡片高度参差。**全库 19,430 款里 16,248 款含 `/`（83.6%）**。

**标签段不写死名单，从库里推导**：全库 19,430 款切成 34,305 个段，
段频次 ≥ 8 的**恰好只有 3 个**，且**全部只出现在末位**：

| 标签段 | 末位出现 | 首位出现 | 中间出现 |
|---|---|---|---|
| `支持网络联机` | 814 | **0** | 0 |
| `支持VR` | 30 | **0** | 0 |
| `附历代合集` | 15 | **0** | 0 |

判据 = **末位 ≥ 8 次** 且 **从未在首位**。第二条是关键护栏：真游戏名哪怕重复收录 8 次，
也一定当过首段；而这类后缀标签永远不可能当首段。

**英文名取法**：取「首个剥尾后不含 CJK、且 ≠ 展示名」的段 —— 不是「第二段」
（中文别名可能有多个）。另有 34 条把版本标注写进了英文段（`红色沙漠/Crimson Desert voices38`），
用 `TAIL_LABEL_RE = /\s+voices?\s*\d*\s*$/i` **只摘这一种已知形态**，不泛化到「任意尾部单词」。

### ② 「原贴内容」—— 数据早就在本地，缺的只是界面

这是「**界面缺字段 ≠ 数据源没有**」的第二次现场（第一次是 v10.48 的 `official_url`）：

| 来源 | 正文字段 | 覆盖 |
|---|---|---|
| 机地 MOD 帖 | `mods.json` → `content` | **8,942 / 8,943 = 100%**（p50 ≈ 1,031 字 / max 6,514） |
| 游侠存档帖 | `saves-youxia.json` → `desc` / `steps` / `shots` | `desc` 100%；有截图 **1,172 条（57.4%）** |
| GTrainers / FearlessRevolution / GCM | 纯链接源 | **没有正文** ⇒ 回 `has:false`，前端**不给入口** |

⇒ 改的是**列表投影与界面**，不是采集。**按需单取**：正文 p50 ≈ 1KB、最大一组 717 条
⇒ 随列表下发约 700KB。列表侧只给 `hasPost` 一个布尔标记，正文走 `/api/res/post` 一次一条。

## 四、踩到的坑

1. ★★ **同一个选择器的规则可能有多条，`exec` 只取首个匹配 ⇒ 断言读到无关的那条**
   断言「原贴弹窗 z-index 必须高于下载弹窗」时，`\.dlpop\{([^}]*)\}` 读到的是**窄屏那条**
   `.dlpop{padding:10px}`（排在全页第一条、**没有 z-index**）⇒ 取值 0 ⇒ 比较退化成
   `130 > 0`，**恒真**；弹窗层级真被改坏它也照样绿。
   ⇒ 修法：正则加 `g` 遍历全部取极值 + 配一条正向锚点钉住「确实读到了具体值」。
   已补 **铁律 49**。
2. ★★ **反向断言必须配正向锚点**（老坑的新现场）：本轮有 4 处反向断言
   （卡面不出现 `/`、修改器无入口、点通道不开弹窗、`has:false`），
   每一处旁边都放了一条「新形态真的渲染出来了」的正向断言 ——
   否则「样本为空」或「整区空白」都会让反向断言白捡一个绿。
3. ★ **jsdom 里点 `<a>` 会走 navigation（未实现 ⇒ 抛 jsdomError）**，会污染「不抛异常」断言。
   测「点下载通道不打开原贴」时用 `addEventListener('click', e => e.preventDefault())` 拦导航，
   **但不 `stopPropagation`** —— 让 document 委托照样跑到，那才是被测行为。
4. ★ **Esc 分层的判据不能用 `pop.hidden`**：`hidden` 要等 180ms 过渡走完才置位，
   用它会在过渡窗口内把「已关」读成「还开着」，连按两次 Esc 就关不掉底下的详情抽屉。
   ⇒ `closePostPop()` 返回「这次是否真关了」（内部用 `postShown` 布尔），Esc 分支据此决定是否继续关下一层。
5. ★ **样式断言只能读 CSS 规则体**（v10.49 同款）：
   本轮所有样式断言都取 `sel{…}` 的 `{…}` 内部，不查「整页含某字符串」——
   后者只要注释里写一个反例就会假绿。

## 五、★ 顺带触发了 v10.45 埋下的一条护栏（本轮最该记的一件事）

`tools/test-download.js` 里躺着一条 v10.45 写的断言：

> ★ 帖子的 `content`（含广告原文）目前无人渲染 —— 这是上面「用户看不到」的前提，
> 前提变了就必须连带把 `content` 一起清（否则这条会红）

判据是 `!/\.content\b/.test(server.js) && !/\.content\b/.test(public/index.html)`。

本轮把 `j.content` 渲染进原贴弹窗 ⇒ **这条立刻变红**（`run-all` 报 `通过 3151 / 失败 1` +
`异常退出：test-download.js (exit 1)`）。**它不是误报，是设计如此** —— 断言自己把条件写在括号里了。

⚠️ 这里有个容易走偏的分叉：看到「旧断言变红」，第一反应往往是「断言过时了，删掉 / 想办法改绿」。
正确的两步是 —— **① 先把数据清干净（它要保的东西）② 再把断言按新前提改写（保留原意图）**。

实测 `data/mods.json` 的 `content`：**8,942 条非空、8,936 条含 URL**（网盘为主，正是用户要点的），
其中含广告站 `52leiqu` 的**只有 17 条** —— 全是同一句源帖结尾的固定引导：
`d.如仍有问题，请看：https://52leiqu.com/problemTutorial。`

**修法**（铁律 17：清洗规则只做一处真源）：

| 层 | 位置 | 做法 |
|---|---|---|
| 真源 | `shared.cleanPostText()` | 行内**域名**命中 `JUNK_HOST_RE` ⇒ **整行删**；不含广告 ⇒ **原样返回**（逐字不动） |
| 抽取（入库前） | `fetchers/jidiModify.js` `shape()` | **先清再截断**（反过来会让「6000 字」的边界算在被删掉的广告行上） |
| 读取（交出正文前） | `data/res-groups.js` `post()` | 兜住「库里还有漏网」；`hasPost` **故意不跟着清**（它只是粗判，不值当对 8,942 条正文跑正则） |
| 存量 | `tools/_clean-post-junk.js` | 一次性洗 17 条；**备份 → `_bak/mods.json.pre-v1050-post`**；`--dry` 可预演；无命中不写盘 |

判据用 **host** 而不是「含 leiqu 字样」—— `leiqupan.com` 是**真网盘**，粗判会误伤（已加断言钉住）。
实测：命中 **17 条（0.19%）**、正文 7,231 → 6,419 字；单元自检 = 无广告**一字不动** / `leiqupan` 保留 / 幂等。

**断言改写**（`test-download.js` 155 → **163**）：删掉「无人渲染」那条，换成守**同一意图**的一组：
① 正向锚点「`content` 确实在渲染层」（防「把渲染删掉」也被判通过）
② `data/mods.json` 正文广告串 **0 条**（这才是原断言真正要保的）
③ `cleanPostText` 的四条单元行为 + `leiqupan` 护栏 + 幂等
④ 抽取层与读取层都调它 + **反向**：抽取层不再把未清洗的 `raw` 直接写进 `content`
