## 3. 改了什么

### 3.1 骨架：固定侧栏 → 浮动侧栏
原来 `.side` 是 `position:fixed`，`.main` 用 `margin-left:230px` 让位。
现在 `.shell` 是 `12px` 内边距的整屏 flex，侧栏是 `230 × calc(100dvh - 24px)` 的圆角卡片
（`.main` 的 `margin-left` 已删）。主区圆角 `10px`，自身滚动，顶栏 `sticky` 吸顶。

### 3.2 新增页签条
`.tabsbar` + `.tab`，当前签下面 2px 主色条 —— 对齐参考站 `.tabs-view / .tab__bar`。
**文案由 `go()` 现写**，不是写死：切「磁力下载」时页签同步变（实测见第 4 节）。
没有做成「可关闭多页签」：这是单页 hash 路由，做多开是假交互。

### 3.3 环境徽标：按 hostname 现判
侧栏品牌行加 `.env-badge`：回环地址显示「本机」，其余显示「线上」。
不写死任何一个 —— 同一个文件既在本机 8123 跑、也在线上容器跑，写死会在另一边说假话。

### 3.4 统计卡改 4 列
原 `auto-fill minmax(160px,1fr)` 在 1440 宽下排成 6+2，第二行两张卡孤零零。
本页恰好 8 张 ⇒ 改 `repeat(4,…)` 后是整齐的 4×2，也与参考站列数一致。

### 3.5 对比度修了两处（主动偏离参考的地方，各写了原因）
- **主按钮底色**用 `--acc`(#bf6a50) 而不是参考的 `#e79379`：后者配白字只有 **2.6:1**，
  按钮文字看不清；同色系压深一档后约 4.4:1。
- **页码选中态**同样改用 `--acc`（白字实底）。
- 统计数字**改回正文黑**（参考站 `.stat-card__value` 就是 `--foreground`），
  原来染主色会让 8 张卡的数字都在抢注意力。

### 3.6 补齐一个漏网的控件
`.dlcfg`（下载器设置）里的「自动起种」是 `<select>`，原来没有任何样式，
掉回浏览器默认灰白控件 —— 与整套皮明显不搭，这版补上。

## 5. 踩坑

1. **换肤最容易"静默退回"**：样式改回去页面照样能开，功能测试全绿也发现不了。
   ⇒ 新增 `test-v10105-admin-theme.js` 守形状（浮动侧栏、4 列、页签钩子、hostname 判断），
   并加了反向断言：旧蓝 `#2563eb` / `#1d4ed8` / `rgba(37,99,235` 必须清零。
2. **反向断言会被注释咬**：本文件里解释「为什么不用蓝色」的注释本身就含 `#2563eb`。
   ⇒ 一律**先剥注释再判**（`stripComments`），并配一条阳性对照（剥完后 CSS 仍 > 8KB 且含 `.side`），
   防止剥注释这一步把整张样式表吃掉（铁律 201）。
3. **`$('vTab').textContent = t` 不能裸写**：老缓存里的 DOM 可能还没有这个节点，
   裸写会抛错把 `go()` 打断 ⇒ 整页白。已加判空，并用反向断言钉住。
4. **`.dlcfg input` 第一眼看"缺框"**：实际是 placeholder 太长被截断（`留空 = %USERPROFILE%\…`），
   量过尺寸 258×32 才确认它一直在 —— 不量就差点去改一个没坏的东西。
