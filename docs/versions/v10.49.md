# v10.49 —— 条目标题统一「单行 + 省略号」

> **一句话结论**：三区卡片（MOD / 存档 / 修改器）里的条目标题由「折 2 行」改成**单行省略**，
> 弹窗「查看全部」里那条「放开折行」的覆盖一并删掉 —— 卡内与弹窗**共用同一条规则**（一处真源）。
> 完整标题不丢：每行 `.t` 都带 `title`，悬停即见全文。四页一致、防线全绿、反证 2/2 成立。

## 一、改了什么

用户口径原文：「卡片中的内容每条显示一行即可多余字显示省略号即可」。

| # | 位置 | 改前 | 改后 |
|---|---|---|---|
| ① | 卡内条目 `.emu-card.grp .gl-i .t` | `display:-webkit-box` + `-webkit-line-clamp:2` **折 2 行** | `white-space:nowrap` + `overflow:hidden` + `text-overflow:ellipsis` **单行省略** |
| ② | 弹窗条目 `.grp-pop .gl-i .t` | 一条把 `line-clamp` 置空、并改成 `display:block` 的**覆盖**（v10.48 加，为了放开折行） | **删除**，直接继承卡内那条 ⇒ 两处同口径 |
| ③ | 注释（弹窗段） | 「在弹窗里必须放开折行，否则列全部和列 3 条看起来一样」 | 「弹窗里也单行省略；区分靠**行数 / 行距 / 顶部搜索条**」 |

`min-width:0` 保留不动 —— 它是省略号能出现的前提（flex item 默认 `min-width:auto`，会拒绝收缩到内容宽度以下，那时省略号不出现，只把兄弟挤走）。

## 二、根因（为什么原来不是一行）

1. **卡内 2 行**：v10.30 那一族卡片统一走「标题固定预留两行」的解法（`.rel-row` / `.x-src` / `.row-card` 都还在用），源头是「只 clamp 不 min-height ⇒ 短标题卡片矮一截」。三区卡片沿用了 clamp 2 行，但**没**跟着走 min-height（它的高度本来就随条目数变）。
2. **弹窗放开**：v10.48 我判断「弹窗要能看出『这是全量』，所以标题放开折行」。用户看过后直接给了相反口径 ⇒ 说明**用折行当信号**这一手没被读到，反而成了「一行长一条、参差」的主要噪声源。
3. ⇒ 结论：区分「卡内 3 条」与「弹窗全量」应该靠**总行数 + 行距 + 顶部搜索条**（本来就都在），不该靠折行。

## 四、踩到的坑

1. ★★ **注释里写完整字面量 = 自己给自己下绊**
   我在注释里把旧写法原样写出（`-webkit-line-clamp:unset;display:block`），一条 `grep` 立刻命中，
   看起来像「旧覆盖没删干净」。⇒ **注释里只做描述性表述**（「把 line-clamp 置空、改成 display:block」），
   别留能被正则完整命中的字面量。这条已写进主源注释提醒下一个人。
2. ★★ **样式断言不能查「整页含某字符串」** —— 必须取规则体内部，否则注释里的反例就能让它假绿。
3. ★★ **`line-clamp` 与 `nowrap` 并存时 clamp 会赢**（clamp 自带换行语义）⇒ 单行省略**静默失效**，
   页面看着「还是折行」，而所有断言仍绿。所以反向断言不可省。
4. ★ **改主源后忘记重建派生页**：回证反证 A 时我只还原了主源、忘了重建，
   于是 `test-resource-page` 读到的仍是退化的派生页（`98/100`）——
   铁律 1「改主源不重建 ⇒ 静默漂移」的又一次现场。**还原也要重建。**
5. ★★ **`run-all` 跑的过程中不许并发跑别的套件**：本轮首跑报 `3080 / 失败 5` +
   `test-emulator-page.js (exit 1)`，看着像真红；**单跑立刻 99/99**。
   根因：我在它跑的 3 分钟里又起了一个 jsdom 套件，两个 jsdom 抢 8123。
   ⇒ 判「是否真红」永远**单跑复现**（同铁律 31「run-all 假红要单跑才算数」）；跑全量时**别并发**。
