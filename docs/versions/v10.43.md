## 三、改了什么

### 1. 新增 `tools/keepalive-8123.vbs`（纯 ASCII，路径运行时推导）

- 端口在 ⇒ `WScript.Quit 0`（**不产生常驻进程**）；
- 不在 ⇒ `shell.Run cmd, 0, False` 隐藏起 `server.js`，轮询核实端口**真的在监听**，写 `_preview/keepalive.log`；
- 承载方是 **`wscript.exe`**（GUI 子系统，不分配控制台）⇒ 从第一帧就不显示窗口，不会「每分钟闪一个黑框」。

### 2. 新增计划任务「GameHub 8123 keepalive」

- 时间触发（`-Daily`）+ **每分钟重复**（登录触发器上挂 `Repetition` 不会反复触发）；
- `ExecutionTimeLimit = 0`（不限制）、`MultipleInstances = IgnoreNew`（不叠实例）。

### 3. `tools/daily-sync.js` —— `stepHealth` 重写

- 不可达时**先等守护一个周期**（75 s，每 5 s 探一次），等到就报「守护已在 Ns 内拉起」；
- 等不到才退回自行 `spawn`（保底）；
- 仍失败则把原因写清：该检查哪个计划任务 —— 原先只说「启动后仍不可达」，无从下手。

### 4. `tools/test-launcher.js` —— 新增 I 段 12 条断言

守 keepalive 的每个关键行为：纯 ASCII / `Option Explicit` / 无硬编码版本目录 / 快速路径 / `Run(cmd,0,False)` / 轮询核实 / 失败写日志 / 端口与 `server.js` 一致 / 路径运行时推导。
