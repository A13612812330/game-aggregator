## ① 「为什么获取不到」—— 根因与修复（铁律 146）

**根因不是接口拿不到，是前端没渲染**：

- 抓包 `/api/download?source=jidi&id=69194701`：接口本就把机地本体的**网盘直链全取回来了**
  （`flatFrom` 自 **v10.27** 起给每条 item 带 `section` 字段，本体/mod/修改器分得清清楚楚）。
- roster 前端的 `queryBody` 机地分支还停留在 v10.66 老口径：「items 混流、会拿 MOD 冒充本体
  ⇒ 只报分区条数、链接需点进源站」—— 那条顾虑**早已被 section 字段解决**，是注释没跟上代码，
  把 18 条直链白白藏了三轮。

**修复**（`gen-roster.js` queryBody 机地分支重写）：

- 按 `section === 'body'` 过滤出**纯本体**，直链卡直出：**网盘类型 + 提取码（pwd）+ 帖子标题
  + 发布日期 + 原帖链接**，超过 20 条折「仅显示前 20 条 · 共 N 条」。
- XD 分支不变（`serverUrl` / needAuth 语义本就正确）。
- **上游异常如实放大**（铁律 147）：实测本轮机地 `/api/misc/post_list` 正被限流
  （8123「返回非 JSON」/ 8124「页面未内嵌 env」/ 线上 HTTP 429）——
  `sections[].error` 原文转报为「上游异常（如实转报）：…」；**error 在场时不下
  「专区没有条目」的排他结论**（可能只是被限流，不是真的没有）。
- MOD 条目不混入（行为探针 ①-3 用 MOD 伪装条目验证过滤生效）。

## ② 数据分析模块 v2

- **数据新鲜度行**：`数据更新至 <builtAt>（每日 09:30 随 daily-sync 自动重生成）`——
  提取前先看口径日期。
- **独立筛选条**（与名单筛选互不影响）：平台（全部/端游/手游可玩）· 来源（全部/机地/XDGAME）·
  时间范围（全部/近 7/30/90 天有更新）+ 重置；**筛选变化即时重算** KPI / 对比卡 / 三榜
  （v10.79 是进视图只算一次，`anaBuilt` 守卫移除）。
- **时间对比卡 2 张**（用户点名的「时间对比」）：近 7 天 vs 前 7 天、近 30 天 vs 前 30 天的
  新增环比（实测 **226 vs 161（↑40%）**、**2,756 vs 2,391（↑15%）**；对当前平台/来源筛选生效）。
- **榜行字段加富**：每行带**来源 tag** + 副字段（热游榜带更新时间 / 最新榜带热度 / 推荐位带日期）。
- **TSV 修正**：更新时间列从带 HTML 标签的 `fmtTs` 换成纯文本 `fmtDate`（TSV 是提取用的，不带 `<span>`）。
- 复制/点行改**事件委托**（绑一次）—— buildAna 随筛选反复重算，逐元素绑定会越绑越多。
